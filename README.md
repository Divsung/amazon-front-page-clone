# Amazon.com Front Page Clone

A front-page clone of Amazon.com created as a practice project using HTML and CSS.

## Technologies Used

- HTML
- CSS

## Features

- Amazon-style navigation bar
- Search bar
- Product categories
- Product sections
- Footer section
- Amazon-inspired layout and styling

## Purpose

This project was created to practice HTML and CSS by recreating the layout and design of an e-commerce website.

## Note

This is a personal practice project and is not affiliated with or endorsed by Amazon.
